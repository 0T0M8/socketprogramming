# C HTTP Server

A small HTTP server written from scratch in C.

The purpose of this project is to understand how HTTP is
built on top of TCP sockets.

## Learning objectives

- TCP sockets
- socket()
- bind()
- listen()
- accept()
- read()
- write()
- sockaddr_in
- HTTP requests
- HTTP responses
- basic HTTP routing

## Project progression

01. Create socket
02. Bind address
03. Listen for connections
04. Accept clients
05. Read HTTP request
06. Parse request
07. Send HTTP response
08. Add routes
09. Serve static files
